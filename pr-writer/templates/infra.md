# Goal

Describe the operational objective and expected system outcome.

# Change Plan

Describe the rollout sequence. Use a numbered list only when order matters.

# Impact

Explain affected systems, users, and expected disruption.

# Rollback Plan

Describe the trigger and concrete recovery procedure.

# Monitoring

Present the signals and thresholds that establish rollout health.

# Validation

Present the pre-deployment evidence for correctness and operational safety.

# Reviewer Guide

Direct reviewers to operational safety, impact, observability, and rollback feasibility.
