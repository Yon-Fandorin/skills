# Goal

State the production issue and the immediate safe outcome.

# Incident

Explain the observed impact and direct root cause without retelling the full investigation.

# Minimal Fix

Explain the smallest safe correction and its safeguards.

# Validation

Present the incident reproduction and evidence that the minimal fix is safe.

# Rollback

Describe the trigger and concrete recovery procedure.

# Follow-up

Describe deferred work briefly only when it is required or already planned; otherwise omit this section.

# Reviewer Guide

Direct reviewers to safety, minimal scope, and reversibility.
