# Goal

Describe the maintainability problem and intended structural improvement.

# Non-goal

State which observable behavior must remain unchanged.

# Before / After

Make the structural difference and responsibility movement clear.

# Decision

Explain the chosen boundary or abstraction and the important trade-off.

# Safety

Describe how behavior preservation is established.

# Validation

Present the evidence that externally observable behavior remains unchanged.

# Reviewer Guide

Direct reviewers to behavior preservation, boundary quality, simplicity, and unnecessary abstraction.
