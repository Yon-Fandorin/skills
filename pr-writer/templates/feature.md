# Goal

State the user problem and intended outcome.

# User Scenario

Show the primary usage flow and its observable result.

# Non-goal

State meaningful exclusions. Omit this section when no clarification is needed.

# Constraints

Explain only constraints that materially shaped the design.

# Decision

Explain the chosen design and important trade-offs.

# Changes

Explain how the main pieces produce the user outcome and how important states or branches behave.

# Validation

Present evidence for the main user scenario, important edge cases, and compatibility.

# Reviewer Guide

Direct reviewers to the highest-value product behavior, edge cases, and interface consistency checks.
