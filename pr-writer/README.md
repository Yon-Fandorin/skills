# PR Writer

실제 변경과 검증 근거로 PR 제목·본문을 작성하고 읽기 쉽게 편집한다.

필요한 사실을 선별한 뒤 Humanizer로 문장을 다듬는다. 검증은 변경과
관련된 결과와 중요한 미확인 범위만 요약하고, 실행 로그·테스트 목록·통계는
검토에 필요한 경우에만 포함한다. 저장소 템플릿의 필수 항목은 유지한다.

최종 diff와 본문을 자체 재검수해 리뷰 중 폐기된 접근이나 이전 설명이
남지 않도록 한다. 기존 문제와 최종 해결을 중심으로 다시 쓰며, 실제 운영에
영향이 있는 이전 동작·마이그레이션 정보는 보존한다.

```text
$pr-writer로 현재 변경의 PR 제목과 본문을 작성해줘.
$pr-writer로 이 PR 본문을 근거와 대조하고 다듬어줘.
```

작성 요청에는 편집을 마친 제목과 본문을 반환한다. PR 생성·수정은 요청한 경우에 수행한다.
새 PR은 항상 드래프트로 생성하며, Ready 전환은 사용자의 명시적 요청이
있을 때만 진행한다.

실행 규칙과 유형별 질문은 [SKILL.md](SKILL.md), 설치는 [저장소 안내](../README.md#설치)를 참고한다.
