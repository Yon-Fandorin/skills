# Skill Reviewer

프레시 컨텍스트 에이전트가 AI Hero 작성 지침과 대상 유형에 맞는 스킬 원문을 읽고, 호출 조건·지침 구조·참조 연결·완료 기준을 검토한다. Anthropic의 작성·평가 지침을 반영해 실제 실패에서 나온 예외 규칙과 제공된 실행·비교 근거도 확인한다.

```text
$skill-reviewer로 이 스킬의 지침과 참조 구조를 검토해줘.
```

기본은 읽기 전용이다. 호출·기능·스킬 유무 또는 버전 간 비교 결과가 있으면 검사하고, 없으면 필요한 최소 평가를 제안한다. 행동 평가를 직접 실행하지는 않는다.

`Ready`는 명시한 구조·근거 검토 범위의 판정이며, 시험하지 않은 실행 동작이나 운영 적합성을 보증하지 않는다. 실행 평가가 없다는 이유만으로 구조 검토를 실패 처리하지 않고 미확인 범위를 적는다. 독립 검수·필수 원문 확인을 완료하지 못했거나 요청한 준비 상태를 입증할 근거가 부족하면 `Review incomplete`, 근거가 있는 주요 결함이 있으면 `Revisions required`로 표시한다.

검토 기준과 보고 형식은 [SKILL.md](SKILL.md), 설치는 [저장소 안내](https://github.com/Yon-Fandorin/skills#설치)를 참고한다.
