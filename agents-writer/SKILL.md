# Agents writer

Apply established or approved policy and the supplied project assessment.
Omit unsupported additions or ask about an essential decision. Review-only
requests return findings without edits.

## Selection and placement

- Keep consequential project conventions, non-obvious exceptions, and costly
  discovery shortcuts. Prune generic competence reminders that add no distinct
  requirement; preserve actual obligations even when a model usually complies.
- Write concise English unless governing instructions select another language.
  State a condition and concrete action; explain surprising exceptions. Choose
  sections from actual needs, not a fixed template.
- Give each rule an applicable scope and one authoritative home. Use conditional
  pointers to detailed docs and skills instead of copying procedures. Include
  exact commands only when discovery is costly or misleading.

## Optional support

- For guided drafting or uncertain keep, move, or remove decisions, read
  [drafting support](references/drafting-support.md); select by need, not model name.
- For host-specific loading, overrides, imports, or the official basis of a
  recommendation, read [official guidance](references/official-guidance.md).

Finish when retained rules are supported and actionable, with stale pointers
and conflicts resolved or reported. Report unverified checks and loading;
file existence alone does not establish that an agent loaded it.
