# Codebase Architecture

공개 진입점, 책임 소유자, 모듈 배치와 의존 경계를 설계하거나 검토한다. 언어나 고정된 아키텍처 패턴을 강제하지 않고 실제 코드와 확정된 방향을 기준으로 판단한다.

```text
$codebase-architecture로 현재 코드베이스의 책임과 의존 경계를 검토해줘.
```

기본은 읽기 전용이다. 결과는 필요한 범위의 모듈 구조, 허용·금지 의존 관계, 공개 경로와 검증 기준이다. 구현이 승인되면 이 기준을 Codewright 또는 구현 담당자에게 전달한다.

실행 지침은 [SKILL.md](SKILL.md), 호환 경로·프로토콜·상태 수명의 판단 기준은 [경계 사례](references/boundary-cases.md), 설치는 [저장소 안내](../README.md#설치)를 참고한다.
